# Photo credits

The live pages intentionally use real photographs from Wikimedia Commons rather than generated imagery.

- `Gokarna Main Beach.jpg` — Kondephy — Creative Commons Attribution-ShareAlike 4.0 International — https://commons.wikimedia.org/wiki/File:Gokarna_Main_Beach.jpg
- `Gokarna Main Beach in January 2023.jpg` — Alexey Komarov — Creative Commons Attribution-ShareAlike 4.0 International — https://commons.wikimedia.org/wiki/File:Gokarna_Main_Beach_in_January_2023.jpg
- `Gokarna main beach, February, 2018.jpg` — Alexey Komarov — Creative Commons Attribution-ShareAlike 4.0 International — https://commons.wikimedia.org/wiki/File:Gokarna_main_beach,_February,_2018.jpg

The image files are referenced remotely because the build sandbox used for this delivery cannot establish outbound TCP connections to Wikimedia. The site keeps visible attribution beside each photograph. In a network-enabled environment, these URLs can be downloaded into `public/photos/` and the three image references changed to local paths without altering licensing obligations.
